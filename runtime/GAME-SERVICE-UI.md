# Retained service and replaceable gameplay view

Start requires every production provider flag, then uses typed provider and
completed-data/SQL verification. It prepares or reuses runtimes, world data,
shaders and the owned installation before allocating GameSession. A static
qualified=true property cannot admit a runtime. runtime.properties remains
qualified=false because real Android/world/gameplay qualification is incomplete.

The foreground worker owns startup, the live wait and repeated bounded cleanup
until GameSession reaches CLOSED. Cancellation and monitor callbacks request
stop; only that worker closes dependencies. Normal close sends source471 Alt+F4,
awaits the actual client, then stops presentation, world/auth and database. A
client timeout retains dependencies and exposes explicit Force stop; forcing is
never recorded as a clean character save. The launcher exposes this action even
after Activity recreation or before a gameplay panel was first bound. Recovery
and actual process-exit acknowledgment survive as small private status facts.

The service owns a renewable10minute partial wake lease and60second heartbeat
through long quiet shader conversion and cleanup. API34+ local compute/gameplay
uses declared specialUse; imports/downloads keep dataSync. Completion removes
heartbeat, releases wake and ends foreground only after known child cleanup and
any explicit support export. Process death remains an interrupted-session gate,
not proof of clean saves.

An Activity binds GamePresentationPanel only to an existing CLIENT_STARTED
owner. It starts no native processes. Pause/stop releases held input, detaches
rendering, mutes audio and drops its view/relay attachment; foreground services
remain owned. The panel provides existing controller/touch/keyboard handling,
stop and support export. Export uses a separate single-flight worker while a
game is active; it reads bounded public facts/whitelisted redacted logs. Child
process PSS is not included in the current performance snapshot, so it is not a
combined memory/bot benchmark. A typed component start is not login/world proof.

Actual Java cleanup/import leases and presentation guards pass in the separate
Game8/World2/Presentation3 fixtures. Full APK/AndroidTest/lint passes; final
launcher-force and wake-heartbeat deltas pass APK/lint25s/54tasks and independent
review. These are compilation/host checks, not Android service/activity or real
gameplay execution. Source and proof: runtime/evidence/game-service-activity-host.json.
